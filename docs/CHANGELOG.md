# 更新记录

## 1.0.2

- 双击截图台缩略图可查看原图，默认适应窗口，保留滚轮缩放与 Esc 关闭。预览采用浅灰工具栏和浅色画布，仅保留左上角置顶图钉与右上角关闭叉号。
- 原图预览右键支持复制、另存为、钉到桌面、保留／取消保留和删除；状态同步至截图台，删除后关闭对应预览。
- 设置页和截图按钮显示当前快捷键；通过「更改」明确进入录入状态，Esc 取消。
- 统一截图台、设置、大图预览与截图工具栏的配色、间距和交互反馈。
- 增加截图台空状态、截图数量及图片操作提示。
- 增加快捷键显示、原图预览及缩放的 WPF 回归验证。

## 1.0.1

- 修复矩形、椭圆无法选中和拖动的问题，新增选中虚线框、颜色/线宽调整及删除。
- 限制形状拖动边界；选中虚线框不参与截图导出。
- 修复隐藏工具栏测量为零导致位置计算错误的问题。
- 将主工具栏与选项栏整体限制在所在显示器工作区内，处理底部、全屏、任务栏及缩放情况。
- 增加拖动边界、工具栏布局和 WPF 事件回归验证。
- 增加离线安装程序、桌面/开始菜单快捷方式及卸载入口。
- 统一源码、测试和安装工程结构，提供可重复执行的打包脚本。
