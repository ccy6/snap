# Snap UI 1.0.2

本次界面调整参考已安装的 frontend-slides skill 中的 Design Aesthetics 与 Paper & Ink 视觉原则，将字体对比、纸张底色、细分隔线与克制的强调色应用于 WPF 桌面界面。

- 主窗口保留原生边框；图片预览使用可拖动、可调整大小的精简窗口，仅显示置顶与关闭按钮。
- 主界面使用暖灰纸色，石墨色正文，低饱和绿色强调主要动作。
- 品牌字标使用 Georgia；中文操作文字保持清晰的系统 UI 字体。
- 截图台以图片为主，数量、时间与保留状态为辅助信息。
- 大图预览使用浅灰工具栏和浅色画布，仅保留置顶图钉与关闭按钮。
- 当前快捷键持续可见，点击「更改」进入录入，Esc 取消。

验证：核心测试及 WPF smoke tests；截图台、设置页和原图预览均已实际渲染检查。
